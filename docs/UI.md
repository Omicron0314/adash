# UI 规范

视觉以 [design/neko.html](design/neko.html) 内嵌的 Rayon M3 页面为准。
参考文件包含多个页面的打包模板；窗口、卡片、字号与间距取自模板中的 `.m3`，不能只使用打包器外层样式。
GPUI 保留原生桌面交互，Kit 负责输入、按钮、导航和卡片行为。

## 已实现的外壳

- 窗口默认 1440×900，32px 标题栏显示应用名、Mock/Live、刷新时间与刷新入口。
- 左侧导航宽 96px。Kit `NavigationItem` 采用图标在上、文字在下的布局，选中图标有 56×32px 胶囊底色。
- 顺序：对话、云资源、主机、AI 流程、身份、片段、端口转发、设置；不显示「连接主机」分组标题。
- 面板外侧 12px 留白，主面板 28px 圆角、28px 内边距。正文 14px，辅助文字 12px。
- 窗口色板在 `adash-app/src/main.rs` 初始化；视图只使用语义角色。

| 语义角色 | 参考浅色值 | 用途 |
| --- | --- | --- |
| `SURFACE` | #f4f1fa | 窗口与导航背景 |
| `SURFACE_CONTAINER_LOW` | #f9f6fe | 主面板 |
| `SURFACE_CONTAINER_LOWEST` | #ffffff | 白色卡片 |
| `SURFACE_CONTAINER` | #f0ecf6 | 次级容器 |
| `SURFACE_CONTAINER_HIGH` | #eae6f0 | 输入区域 |
| `PRIMARY` | #4b49c8 | 操作、强调、回放 |
| `PRIMARY_CONTAINER` | #e2dfff | 用户消息、产品徽标 |
| `SECONDARY_CONTAINER` | #e2e0f9 | 导航选中、预算卡片 |
| `TERTIARY_CONTAINER` | #ffd8e4 | 待处理卡片 |
| `SUCCESS` | #246b3a | 资源运行状态 |
| `INVERSE_SURFACE` | #16161d | 终端区域 |

尺寸使用 Material `rem` 工具（接收设计像素，随文字缩放）；窗口边缘和发丝线可用 px。
非交互卡片使用 Kit `CardSurface` 薄组合，24px 圆角、16–20px 内容内边距。
`MaterialCard` 的 `Styled` 修改外层 wrapper，不能把它的外层 padding 当成内部内容布局。
原始 HTML、脚本和字体不参与应用构建，不修改 submodule。

## 对话与账户概览

主面板占剩余空间；右侧为独立的 344px 账户概览栏，窗口小于 1280px 时收为 300px。
两栏分别滚动。欢迎区标题 48px，附有盘点资源、寻找省钱机会、查看流程三个快捷入口。
开始对话后收起欢迎区与初始介绍，给消息和计划卡片留出空间。

- 用户消息右对齐，使用 primary container；助手消息左对齐，正文没有气泡背景。
- 本地应答标注离线模式。中间状态放在标题行；工具记录显示在消息下。
- 计划卡片显示资源操作、成本、风险、可逆性与确认/取消入口。
- 底部为单层 M3 圆角输入（56px 高、28px 半径），Kit `Input` 只画文字与光标，不含图标与提示文字；
  Enter 发送，生成中可点击「停止」，取消完成前不启动下一轮。
- 右栏为余额、本月花费、预算、资源计数和待处理卡片。余额卡注明资源月成本估算；预算超支显示金额。
- 资源计数跳转带筛选的清单；待处理入口生成计划，不直接修改云资源。

所有输入框统一使用本仓库的 `widgets::rounded_input` / `rounded_area`：Kit 负责编辑、
选择、剪贴板、IME 与光标，外层圆角容器负责 M3 外观；表单使用上方标签（`labelled_input`）。
不使用 Kit `TextField` 的 4dp 方角外观。

## 云资源

40px 标题、右侧搜索、产品/地域/项目筛选。主体为可滚动的两列白色资源卡片，显示产品图标、
状态、名称、规格、项目和月成本。选择资源后，右侧白卡显示事实详情与现有操作入口。
IP 只显示一次；闲置资源显示「未使用」，不与主机停机混用。

搜索订阅输入状态变化；点击卡片、切换筛选、复制 ID、查看流程图与打开主机会话沿用原领域数据。

## AI 流程

32px 项目标题、项目筛选、只读 DAG 画布、右侧检查器与底部执行回放栏。
画布为点阵背景，服务节点为白卡，绑定/声明边用实线，推断关系用虚线。
节点可选择，右栏显示节点事实，并可跳到云资源中查看；未选择节点时显示项目概览和连线图例。
回放高亮使用 primary。默认密度在 1440×900 下显示示例项目全部节点。

「适应窗口」当前切换紧凑布局；自由缩放、拖动画布和导出仍待实现，不将这些能力视作已完成。

## 主机（M6）

主机页保存、编辑和删除 SSH 目标，可为主机选择已保存的身份、勾选多台用于批量片段。
身份页管理 SSH Agent、密码与私钥，密码/口令写入系统钥匙串。片段支持多行命令，
可在当前会话执行或在选中主机上并发执行（最多 8 个连接），分别显示输出和退出码。
端口转发规则绑定主机，本地与远程监听只绑定回环地址；每条规则独立启动、取消、停止。

会话保留终端、文件、监控三个入口：

- 终端按 VT 行和样式范围绘制，保留空格、中文宽字符、多色、背景与光标，使用设置中的等宽字体。
  PTY 尺寸跟随视口，滚轮查看历史，键盘支持 Ctrl/Alt、导航及功能键；Ctrl+Shift+C 复制当前屏幕，
  Ctrl+V / Ctrl+Shift+V 粘贴。中文输入法预编辑仅在本地显示，提交后发送，弹窗与失焦时禁止发送。
- 文件页左右分为目录与文本编辑器，目录列表虚拟化；可输入路径、上一级、新建、重命名、删除空目录/文件、
  上传和下载。传输显示进度、可取消，不覆盖已有上传/下载目标；文本编辑限 UTF-8、2 MiB。
  未保存修改带标记，切换文件或关闭前确认；保存时先暂存，替换失败保留原文件或可恢复备份。
- 监控读取 `/proc` 和 `df` 的实际样本，按设置间隔刷新，CPU 使用连续样本差值，内存与磁盘按 GiB 换算。

首次连接要求核对主机指纹，指纹变更拒绝连接。连接状态和指纹独占一行，不挤占标题操作。
断线可重新连接；会话关闭时停止终端、转发和后续排队操作。

## 设置

沿用 catussh 的分类：通用（语言、浅色/深色/跟随系统、关闭会话确认、自动打开终端、最近主机数量）、
终端（字号、等宽字体、快捷键与实时预览）、连接（超时、监控间隔、已保存指纹、配置路径）、
关于（版本、组件、云账户、SDK 模型与工具白名单）。没有对应能力的 catussh 选项不显示。
