# 演示剧本（5 分钟）

> 状态：待 M5 定稿。下面的路径是目标，随实现调整。

1. **开场（30s）**：打开 app，主页就是对话。右上角 `Mock` 徽标说明现在不花钱。
   右侧概览一眼看到：余额 ¥xxx、本月花费 ¥xx、预算用到 62%、14 个资源、2 条待处理。
2. **许愿（90s）**：「把这个仓库部署上线，最便宜的地域」。
   代理先折叠一行「查询 3 个地域价格」，再给计划卡片：1 台轻量主机 + 复用现有 MySQL，
   月成本 ¥xx，可逆，风险无 → 点「确认并执行」。
3. **兑现（60s）**：切到「云资源」，新主机出现（状态点从 Pending → Running），
   详情里能看到 `adash:shop-api` 标签。
4. **讲清关系（90s）**：切到「AI 流程」，选 `shop-api` 项目：
   GitHub → UHost ×2 → ULB → EIP，UDB/Redis 挂在主机下。点 `▶ 回放`，
   高亮按部署顺序走过一遍 —— 这就是「这个项目用了哪些服务」。
5. **省钱（60s）**：回到对话说「有浪费的吗」。代理列出 2 个孤儿 EIP、1 块未挂载云盘，
   带金额的计划卡片 → 确认后概览的月花费下降。
6. **收尾（30s）**：强调边界——没有确认就没有变更；凭证从不进模型上下文。

## 备用 2 分钟版

打开 → 一句话部署 → 确认 → 资源页看到新主机 → 流程页回放 → 结束。
