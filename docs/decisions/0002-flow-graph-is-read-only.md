# ADR 0002：AI 流程页只读，数据来自领域层

- 状态：已接受
- 日期：2025-10-30

## 背景

需求里的「重点演示一个流程图，参考 n8n，让用户看到『一个项目用了哪些服务』」。
n8n 是可视化编排器（可编辑）；而我们同时要求「代理是唯一改云上状态的入口」，
且任何变更都必须经过计划卡片确认。

## 决定

AI 流程页是**只读的关系视图**，不是编排器：

- 节点 = 项目下的真实资源 + 外部端点；边 = 有证据的依赖（EIP 绑定、UDB 挂载、ULB 后端、
  部署记录里声明的依赖、可选的主机实测连通性）。
- 图由 `adash-core::flow` 生成，GUI 只做布局与绘制；**模型不画图**，代理只维护关系与触发执行。
- 图的证据来源在节点详情里逐条列出（可点回资源），避免「好看但不真」。

## 后果

- 好处：与「确认才变更」的安全模型一致，演示不会因为误操作花钱；图里的每个节点都能点进真实资源。
- 代价：用户不能直接在图上连线新建资源；想改只能通过对话生成计划。
  如果以后要做编排，必须先把「图 → 计划 → 确认」这条链路设计清楚，再让画布可编辑。
