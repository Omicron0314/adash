# 验收与人工回归

先运行 `cargo test --workspace`、`npm --prefix agent/runtime test` 和
`ADASH_SSH_INTEGRATION=1 cargo test -p adash-ssh --test localhost`。
最后一条未设置环境变量时会跳过真实连接，不能把这种通过当作 SSH 验收。

## 自动化覆盖

- SDK：真实 SDK/扩展/Rust CLI + 本地模型端点；启动等待、10 工具白名单、计划拒绝、
  缺少批准令牌拒绝、批准消费、确认期间取消、流式中止、模型错误、启动失败与干净退出。
- 脱敏：伪造的 UCloud 私钥标记不出现在模型请求、GUI 事件或 SDK 会话文件；模型 API key 不进入会话/事件。
- SSH：临时非特权 sshd，未知/变更指纹拒绝、命令输出和退出码、SFTP 文本/二进制限制、
  权限及符号链接、上传/下载拒绝覆盖与取消清理、空目录创建/删除、重命名、监控、PTY 输入和尺寸、双向转发。
- 保存失败：注入替换/回滚失败，验证原文件恢复或仍在错误信息指向的备份路径。
- 终端：彩色文字同行、空格和宽字符、控制/导航/功能键、IME 预编辑本地保存、仅提交一次、失焦/禁用不发送。

## 原生窗口与手动操作

`python3 scripts/ssh-smoke.py` 启动隔离状态的原生应用和临时 sshd，关闭窗口或 Ctrl+C 后清理。
可选 `--tab files`、`--tab monitor`、`--untrusted`、`--capture /tmp/ssh.png`。
截图仅证明布局与展示的数据，下面的交互清单需另外逐项操作；未标记项不视作已人工验收。

- [ ] 1280×800、1440×900、1920×1080 下无控件溢出；长名称在详情中可读
- [ ] 主页 Enter 发送、流式更新、停止后可再次发送，输入框没有图标/提示文字
- [ ] 计划取消不执行，确认后 Mock 流程记录增加；不能把执行记录视作真实资源已部署
- [ ] 云资源筛选/搜索/详情/复制 ID/流程跳转；AI 流程节点、回放、项目切换
- [ ] 主机添加/编辑、为已有主机更换身份、保存错误保留表单；会话存在时拒绝编辑/删除
- [ ] 首次连接显示完整指纹，信任后连接；指纹变化拒绝连接
- [ ] 终端中输入英文和中文，Ctrl+C 中止命令，滚动历史、复制/粘贴、调整字号与窗口大小后 `stty size` 对应
