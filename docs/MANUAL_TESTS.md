# 人工测试清单

自动化测试跑完（`cargo test --workspace`）后逐项确认；涉及真实账户的步骤默认**不跑**。

## UI（Mock）

- [ ] 1280×800、1440×900、1920×1080 三档下无横向滚动、无文字截断
- [ ] 导航折叠（窗口宽 < 1180）图标与 tooltip 正确
- [ ] 明/暗主题、字号 100% / 150% / 200% 下布局不破
- [ ] 主页：发一条消息 → 流式输出 → 工具调用可展开 → 概览数字随刷新变化
- [ ] 主页：计划卡片「取消」不产生变更；「确认并执行」后资源页出现新资源
- [ ] 云资源：筛选组合、搜索、详情抽屉、复制 id、空态
- [ ] AI 流程：平移缩放、节点选中、回放逐条高亮、项目切换、空态跳转对话
- [ ] reduced motion 开启时脉冲动画消失，其它动效仍可用

## 代理

- [ ] pi 未安装 / 模型未配置时，界面给出可读错误而不是崩溃
- [ ] `--no-builtin-tools` 生效：代理无法执行 shell
- [ ] 会话文件里搜不到私钥
- [ ] 计划过期后 `apply` 被拒绝

## 真实账户（危险，需显式确认）

- [ ] 只跑 read：`UDASH_LIVE=1` 下资源/账单数字与控制台一致
- [ ] 单台最小规格主机：创建 → 确认 → 停止 → 释放，全程走计划卡片
- [ ] 释放后概览与流程页同步消失

## 打包

- [ ] `cargo build --release` 后 `adash-app` 与 `adash-tool` 在同一目录可独立运行
- [ ] 系统无 Rust 环境下安装包可启动，图标与 `.desktop` 条目正确
